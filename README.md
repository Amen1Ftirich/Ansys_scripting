# Ansys_scripting
Ansys scripting examples and applications I did 
This contains the script gratingscriptingexample.lsf which is the script for the grating example that simulates the transmission of planewave at 1300-1800 nm through a periodic array of rectangles ( n(ref index) = 3.4, size = 0.5x0.5 micro m^2, period 1micro m)
vusalizedresults_grating example is the result graph.
